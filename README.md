# Portafolio web con Bootstrap

Sitio multipágina adaptable con presentación profesional y contacto.

## Tecnologías

- HTML
- Bootstrap 5
- CSS

## Instalación y ejecución

Abre `index.html` o `contacto.html` con Live Server.

## Uso

Navega entre páginas y prueba el formulario.
